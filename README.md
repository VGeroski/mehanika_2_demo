# Mehanika 2 (WebGL)

Statička WebGL2 verzija simulacije sfernog kretanja.

Demo: https://vgeroski.github.io/mehanika_2_demo/

## Lokalno (izvor)

```text
python serve.py
```

## Produkcija (docs/)

```text
npm install
npm run build
python serve.py --root docs
```

Zatim commit + push `docs/`. GitHub Pages: branch `master`, folder `/docs`.

Kontrole: pauza/reset/brzina u panelu · pinch zoom · 2× tap = kamera · YZ/izo pogledi · Snimi WebM.
